# SafeSettle Frontend (React)

## Status: Reserved for Upcoming Milestone

This directory is designated for the React application in subsequent milestones.

### Planned Capabilities
- **Interactive Geospatial Dashboard**: MapLibre / Leaflet visualization of habitations, shelters, road network conditions, and hazard zones using GeoJSON from the FastAPI backend.
- **Authority Console**: Verification queue for citizen reports, status override toggles, and feasibility analysis reviews.
- **Relocation Plan Visualizer**: Clear visual mapping of habitation-to-shelter assignments, capacity utilization gauges, and route viability indicators.
- **Citizen Portal**: Clean mobile-first interface for crowdsourced hazard reporting (location, description, photos).

*Note: In accordance with Milestone 1 specifications, no frontend packages or code are initialized yet.*
